# Ready Projects

Five small apps. Each is one self-contained HTML file with no build step and no dependencies.

## Run
Double-click `index.html` (or any app's `index.html`) to open it in your browser.

## Apps
| Folder | What it does |
|---|---|
| `snake/` | Classic Snake with a saved high score |
| `habit-tracker/` | Daily habits, 7-day grid, streak counter |
| `expense-tracker/` | Income and expenses, balance, spending chart |
| `kanban/` | Drag-and-drop To do / Doing / Done board |
| `flashcards/` | Paste `Question :: Answer` lines, flip and shuffle |

Data is saved in your browser's localStorage.

## Push to GitHub
```bash
git remote add origin https://github.com/<you>/ready-projects.git
git branch -M main
git push -u origin main
```
